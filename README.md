# 👾 Game of Life (Conway's Cellular Automaton)

Реализация легендарного клеточного автомата «Жизнь» Джона Конвея на языке **C11**. Проект поддерживает два независимых варианта сборки: минималистичную терминальную версию на ANSI-escape-последовательностях и интерактивную версию на базе библиотеки `ncurses`. 

Один `Makefile` собирает оба бинарника (статический и динамический) в изолированную директорию `build/`.

---

## ✨ Возможности

* **Два независимых билда из одного репозитория:**
  * `game_of_life_static` — минималистичная версия без внешних зависимостей. Рендеринг через `\x1b[...` работает «из коробки» в любом POSIX-терминале.
  * `game_of_life_dynamic` — интерактивный интерфейс на `ncurses` (пауза, пошаговый режим, редактор клеток, регулировка скорости, выбор режимов отображения).
* **Квадрантный рендеринг (только в dynamic):** Каждая ячейка выводится четырьмя субпикселями через Unicode-блоки (`▘▝▖▗▀▄▌▐▚▞▛▜▙▟█`). На стандартном экране 80×24 это дает эффективное разрешение **160×48**.
* **Цвет по возрасту клетки:** Свежие клетки — зеленые, «зрелые» — голубые, долгожители — синие. На планерах и осцилляторах это создает живую, легко читаемую инфографику.
* **Динамический размер:** Сетка автоматически адаптируется под размеры окна терминала и корректно обрабатывает сигналы `SIGWINCH` / `KEY_RESIZE`.
* **Загрузка узоров (.cells):** Текстовый формат, где символы `# O o * X x 1` означают живую клетку. Узор автоматически центрируется и обрезается под текущий размер экрана.
* **Каталог пресетов:** В папке `materials/` подготовлены классические фигуры для проверки логики автомата.

---

## 📋 Требования

* Компилятор с поддержкой **C11** (`gcc` или `clang`).
* Утилита автоматизации сборки `make`.
* Библиотека **ncurses** (для `dynamic`-версии). *На macOS поставляется вместе с Xcode Command Line Tools.*
* Локаль с поддержкой **UTF-8** (`LANG`/`LC_ALL`) для корректного отображения квадрантов. В противном случае игра автоматически откатится в ASCII-режим.

## 🛠 Сборка и Запуск

### Компиляция

Для сборки обоих вариантов выполните команду в корне проекта:
```sh
make game_build
```

После успешного выполнения в корне появится папка `build/`:
```text
build/
├── game_of_life_dynamic
└── game_of_life_static
```

### Запуск Static-версии (ANSI)
```sh
./build/game_of_life_static             # Случайная генерация поля
./build/game_of_life_static 42           # Случайная генерация с seed=42
./build/game_of_life_static g            # Предустановленный пресет (три планера)
./build/game_of_life_static materials/acorn.txt  # Загрузка конкретного файла
```
*Выход из статической версии: `Ctrl + C`.*

### Запуск Dynamic-версии (ncurses)
```sh
./build/game_of_life_dynamic             # Запуск в интерактивном режиме
./build/game_of_life_dynamic materials/gosper.txt # Запуск с узором
```

## 🕹 Управление (в Dynamic-версии)

| Клавиша | Действие |
| :--- | :--- |
| `q`, `Esc` | Выход из игры |
| `Space` (Пробел) | Пауза / Продолжить |
| `n` | Сделать один шаг (работает только в паузе) |
| `r` | Сгенерировать случайное поле |
| `c` | Полностью очистить поле |
| `v` | Сменить режим рендеринга: `quad` ➔ `block` ➔ `ascii` ➔ `quad` |
| `x`, `Enter` | Инвертировать клетку под курсором (живая/мертвая) |
| `↑` `↓` `←` `→` / `h` `j` `k` `l` | Перемещение курсора по полю |
| `g` | Разбросать горсть случайных клеток вокруг курсора |
| `[` / `]` | Замедлить / Ускорить симуляцию |
| `L` | Загрузить узор из файла (ввод пути в статус-строке) |

## 📄 Формат файлов узоров

Простой текстовый формат (по одной строке на ряд поля).
* **Живая клетка:** Символы `#`, `O`, `o`, `*`, `X`, `x`, `1`.
* **Мертвая клетка:** Любой другой символ (включая точки `.` и пробелы).
* **Комментарии:** Строки, начинающиеся с `!`, полностью игнорируются (совместимость с `.cells`).

**Пример (Планер):**
```text
! Глайдер (планер)
.#.
..#
###
```

**Пример (Пушка Госпера - `materials/gosper.txt`):**
```text
........................#...........
......................#.#...........
............##......##............##
...........#...#....##............##
##........#.....#...##..............
##........#...#.##....#.#...........
..........#.....#.......#...........
...........#...#....................
............##......................
```
*Примечание: Узор не обязан совпадать с размерами экрана — он автоматически отцентрируется.*

## ⚙️ Технические детали

* **Тороидальная топология:** Края поля логически «зациклены». Клетки, выходящие за правый край, появляются слева, создавая бесконечное пространство для движения (например, космических кораблей).
* **Двойная буферизация:** Состояние сетки разделено на два независимых массива (`cur` и `next`). Пересчет поколения происходит за счет быстрого свопа указателей на строки — сложность \(O(H)\) вместо копирования всего массива через `memcpy`.
* **Массив возрастов:** Отдельный слой `age[][]` отслеживает, сколько итераций клетка непрерывно остается живой. Значение сбрасывается при смерти и насыщается на отметке 250. Используется исключительно для динамического окрашивания.
* **Легковесный ncurses:** Для UTF-8 вывода используется стандартный `mvaddstr` (вместо `mvaddwstr`). Благодаря этому проект компилируется на macOS, Linux и средах MSYS2/MinGW без флагов `_XOPEN_SOURCE_EXTENDED` и линковки тяжелой `-lncursesw`.
